# Cymnatic Web

Materi dan checkpoint eskul Cymnatic untuk belajar web (HTML, CSS, JavaScript).

Semua materi ada di folder `checkpoint`. Satu folder berisi hasil akhir satu pertemuan:

| Folder | Isi |
|---|---|
| `P01` | Kartu nama digital (HTML dasar) |
| `P02` | Linktree tahap 2 (list dan link) |
| `P03` | Linktree tahap 3 (CSS dasar: warna dan font) |
| `P04` | Linktree tahap 4 (box model, tombol, hover) |
| `J01` | JavaScript pertama (console.log, variabel, sapaan) |

Kode `P` untuk pertemuan HTML dan CSS (Selasa), kode `J` untuk pertemuan JavaScript (Kamis).

Tertinggal atau file hilang? Pakai folder pertemuan sebelumnya sebagai titik awal.

## Di komputer lab

1. Klik dua kali `Update_Cymnatic.bat`.
2. Tunggu sampai folder `Cymnatic` terbuka di Desktop.
3. Materi ada di `Cymnatic\Materi`. Kerjakan tugasmu di `Cymnatic\Kerjaku`.

Isi `Materi` selalu diperbarui setiap kali skrip dijalankan, jadi jangan menyimpan pekerjaanmu di sana. Di akhir sesi, salin folder `Kerjaku` ke flash drive atau kirim ke dirimu sendiri.

## Di laptop sendiri

Unduh semua materi lewat tombol Code, lalu Download ZIP, atau buka halaman Pusat Materi.

## Cara membuka

Buka folder pertemuan di VS Code (File, lalu Open Folder), buka `index.html`. Simpan dengan Ctrl+S, lalu refresh browser dengan F5.
